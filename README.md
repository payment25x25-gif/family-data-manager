# 📊 مدير بيانات العائلات - Family Data Manager

موقع بسيط وسهل لعرض وإدارة بيانات العائلات باستخدام HTML و CSS و JavaScript.

## 🚀 المميزات

- ✅ **واجهة بسيطة وسهلة الاستخدام**
- ✅ **وضع داكن وفاتح** (Dark/Light Mode)
- ✅ **عرض بيانات العائلات في جداول**
- ✅ **نظام تسجيل دخول للمشرفين**
- ✅ **لا يحتاج إلى خادم أو قاعدة بيانات**
- ✅ **يعمل على جميع المتصفحات**

## 📁 هيكل الملفات

```
family_data_manager_simple/
├── index.html      # الصفحة الرئيسية
├── styles.css      # التصميم والألوان
├── script.js       # الوظائف والتفاعلات
├── data.js         # بيانات العائلات
└── README.md       # هذا الملف
```

## 🎯 كيفية الاستخدام

### 1. فتح الموقع

ببساطة، انقر مرتين على ملف `index.html` أو افتحه في المتصفح.

### 2. التنقل بين الصفحات

- **الصفحة الرئيسية**: عرض العائلات المتاحة
- **صفحة العائلة**: عرض بيانات العائلة في جدول
- **تسجيل الدخول**: للمشرفين فقط

### 3. تسجيل الدخول

**بيانات الاختبار:**
- اسم المستخدم: `admin`
- كلمة المرور: `admin123`

## 🔐 تغيير بيانات تسجيل الدخول

افتح ملف `data.js` وغيّر:

```javascript
const adminCredentials = {
    username: "admin",      // غيّر هنا
    password: "admin123"    // غيّر هنا
};
```

## 📝 إضافة عائلة جديدة

افتح ملف `data.js` وأضف عائلة جديدة:

```javascript
const familiesData = {
    "آل مزهر": [...],
    "آل راشد": [...],
    "عائلتك الجديدة": [        // أضف هنا
        {
            "الاسم": "محمد علي",
            "1438": "مشارك",
            "1439": "مشارك",
            // ... أضف الأعمدة الأخرى
        }
    ]
};
```

## 🎨 تخصيص الألوان

افتح ملف `styles.css` وعدّل الألوان:

```css
:root {
    --primary-color: #3b82f6;      /* اللون الأساسي */
    --secondary-color: #10b981;    /* اللون الثانوي */
    --bg-color: #ffffff;           /* لون الخلفية */
    --text-color: #1f2937;         /* لون النص */
}
```

## 🌙 الوضع الداكن

يتم حفظ تفضيل الوضع تلقائياً في المتصفح. انقر على زر الشمس/القمر لتبديل الوضع.

- ✅ الهواتف الذكية والأجهزة اللوحية

## 🚀 النشر على الإنترنت

### خيار 1: Netlify (الأسهل)

1. اذهب إلى [Netlify.com](https://netlify.com)
2. اسحب مجلد المشروع إلى صفحة Netlify
3. انتظر النشر - ستحصل على دومين مجاني!

### خيار 2: Vercel

1. اذهب إلى [Vercel.com](https://vercel.com)
2. اختر "Import Project"
3. اسحب مجلد المشروع
4. انتظر النشر

### خيار 3: GitHub Pages

1. أنشئ مستودع على GitHub
2. ارفع ملفات المشروع
3. اذهب إلى Settings → Pages
4. اختر الفرع الرئيسي
5. الموقع سيكون على: `https://username.github.io/repo-name`

## 🔧 التعديل والتطوير

### في VSCode:

1. افتح المجلد في VSCode
2. استخدم "Live Server" extension لمعاينة التغييرات الفورية
3. عدّل الملفات حسب احتياجك

### الملفات التي قد تحتاج تعديل:

- **data.js**: لتغيير البيانات والبيانات الحساسة
- **styles.css**: لتغيير التصميم والألوان
- **index.html**: لإضافة صفحات جديدة
- **script.js**: لإضافة وظائف جديدة

## 💾 حفظ التغييرات

التغييرات تُحفظ تلقائياً في الملفات. ما عليك سوى:

1. عدّل الملف
2. احفظه (Ctrl + S)
3. أعد تحميل الموقع في المتصفح (F5)

## 🐛 حل المشاكل

### الموقع لا يظهر

- تأكد من فتح ملف `index.html` بشكل صحيح
- جرّب متصفح آخر
- افتح وحدة التطوير (F12) وتحقق من الأخطاء

### البيانات لا تظهر

- تأكد من أن ملف `data.js` موجود
- تحقق من أسماء العائلات في `data.js` و `script.js`
- افتح وحدة التطوير (F12) وتحقق من الأخطاء

### الوضع الداكن لا يعمل

- امسح ذاكرة التخزين المؤقت (Ctrl + Shift + Delete)
- أعد تحميل الصفحة

## 📞 الدعم

إذا واجهت أي مشكلة:

1. تحقق من وحدة التطوير (F12)
2. اقرأ رسائل الخطأ بعناية
3. تأكد من أن جميع الملفات موجودة في نفس المجلد
